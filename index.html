§ 01 — Premise

A short story about scaling messy financial data down to something queryable.

Two years ago, I inherited a RAG pipeline at Accenture that took five days to ingest a batch of financial documents. Five. Days. Analysts would kick off a run on Monday and pray on Friday.

“The interesting work in AI right now isn't the model — it's the plumbing around it.”

I rebuilt it as a distributed framework with a tiered embedding strategy, delta collection promotion in Milvus, and a Parquet-based reprocessing loop for the inevitable failures. The 5-day job became a 24-hour job. Query accuracy hit 95%. Analysts stopped praying.

Then I built Genie — a seven-agent orchestrator that sits on top of it. That's what you should probably ask me about.

§ 03 — Genie, up close

Seven agents walk into a financial query.

Each agent has a narrow job and about six tools. The system is a polite argument between them, moderated by a reasoning agent that decides what a user actually wants when they ask something vague like “how did we do last quarter?”

AGENT 01

Query Clarifier

First line of defense. Catches under-specified prompts before they poison downstream retrieval.

tools · 4
AGENT 02

Reasoning Agent

Decomposes multi-intent queries into ordered sub-queries. Routes to specialist agents.

tools · 7
AGENT 03

Entity Resolver

Hits the master company collection to disambiguate “Apple” from “Apple Hospitality REIT.”

tools · 5
AGENT 04

Macro KPI Agent

3-stage pipeline: entity extraction → KPI taxonomy lookup → SQL generation. My favorite.

tools · 6
AGENT 05

Vector Retriever

Milvus-side semantic search across 3,000+ company profiles. Knows when to widen top-k.

tools · 5
AGENT 06

Web Fallback

When internal sources come up dry, this agent crawls. Cites aggressively.
